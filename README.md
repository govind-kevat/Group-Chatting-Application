# Group Chat Application

A multi-user group chat built with Java Swing (GUI) and socket programming.

## Features
- Multiple users chat in one group
- WhatsApp-style interface with timestamps
- Scrollable chat, Enter key to send

## How to run
1. Run Server.java (once)
2. Run UserOne, UserTwo, UserThree

## Tech
Java, Swing, Sockets, Multithreading
